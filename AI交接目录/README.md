## 目录

- `功能模块/01…12/`：每组独立 README＋设计图，一共12张图、36个界面。
- `教室配置/501-材料表征实验室/`、`502-化学分析实验室/`：教室职责、配置说明及代码路径。
- `软件/miniprogram/classrooms/`：唯一可执行教室配置来源。
- `软件/miniprogram/modules/`：按预约、认证权限、仪器、试剂、样品、日志拆分。
- `软件/miniprogram/pages/`：已开始实现的14个原生小程序页面。
- `软件/tests/`、`软件/scripts/`：自动化检查。
- `参考资料/`：原始HTML需求与生成图说明；原始规则存在冲突时按需求总览中的取舍接续。

## 已开始的软件

微信原生小程序，当前是单设备本地演示，版本0.1.0。可以演示预约全流程、样品登记并关联预约、试剂领用及持久化。正式账号、服务端事务、多设备同步尚未接入。

进入 `软件/` 执行 `npm test` 和 `npm run check`，无需安装依赖。用微信开发者工具导入同一目录；详细步骤见运行与验证。

## 可直接发给下一个 AI

> 请先读本目录的 AGENTS.md、NEXT.md 和需求与规范/架构与拆分.md，再检查现有代码与测试。按“教室配置＋功能模块”继续实现，禁止把全部业务塞进一个文件，禁止复制每个教室的一套业务。保留已经确定的白底黑绿简洁视觉。先验证当前14页在微信开发者工具中的实际编译与运行，修正真实问题，再依照实现矩阵推进下一项。每次更新NEXT.md，区分本地测试、微信真机和真实后端证据；不要把图片页数当成实现数量。
