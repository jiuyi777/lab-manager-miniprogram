# 运行与验证

## 本地检查

电脑需已有Node.js。当前无第三方依赖，无需npm install。

```powershell
cd 软件
npm test
npm run check
```

也可直接 `node --test tests/*.test.js` 与 `node scripts/check.js`。

## 微信开发者工具

1. 导入 `软件` 目录，工具读取project.config.json，miniprogramRoot为miniprogram/。
2. 当前appid为touristappid，适用无正式账号的本地工具演示；若工具不支持游客模式或要真机预览，用用户自己的AppID替换。不得编造AppID。
3. 编译后默认进入演示账号页。无需学校密码，不会真实登录学校系统。
4. 学生登记样品→选择仪器→选未来同日开放时段→提交。页面默认次日08:00，可自行调整。
5. 我的→退出并更换演示账号→老师或管理员→管理工作台审批。
6. 再切回学生，在真实预约时段内打开详情签到→结束→管理员确认归还。
7. 重启后检查预约、样品、库存和通知恢复。测试用例的虚拟时钟用于自动化，正式演示页面没有绕过时间的按钮。

## 证据范围

- 15项Node自动测试：状态转换、跨实验室权限、重叠/相邻、重复请求、版本冲突、培训、过期、库存负数和超领、样品归属、存储失败回滚、页面控制器闭环及新服务恢复。
- 静态检查：14个路由的文件、JS/JSON、WXML方法误用、事件处理器、文件长度、页面分层和链接。
- 页面控制器用wx轻量桩验证事件到业务，**不是微信渲染引擎**。
- 当前电脑未发现微信开发者工具，官方WXML/WXSS编译、真机样式、微信生命周期、真实网络均未验证。
