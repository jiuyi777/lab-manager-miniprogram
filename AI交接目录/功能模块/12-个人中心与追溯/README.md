## 模块职责

代码归属：`pages/profile/、logs/；modules/audit/；modules/auth/policy.js`（相对于 `软件/miniprogram/`）。只处理本模块职责；跨模块数据通过服务接口调用。

## 34 个人中心

- A 查看本人身份和所属实验室。
- B 进入预约、样品、领用及培训记录。
- C 修改密码、联系管理员或退出。

当前：已实现姓名角色、预约/样品/通知入口、切换演示账号。

## 35 操作日志

- A 按操作人、时间和类型筛选。
- B 追踪谁在何时修改了哪条记录。
- C 展开查看修改前后内容。

当前：已实现只读日志列表；筛选和中文动作详情格式待补。

## 36 培训资格

- A 查看各仪器的培训资格及有效期。
- B 查看培训记录并联系负责人。
- C 管理员可授予或撤销使用资格。

当前：资格校验和种子数据已实现；培训名单与有效期维护页面待做。

## 接续规则

- 先核对现有代码和上面的状态，再实现缺项，不创建第二套同名业务。
- 页面只处理交互与展示；权限、状态转换、校验集中在对应业务模块。
- 影响共用规则时检查其他页面与教室，修改源头并补相应测试。
- 图片里的 A/B/C 是评审标注，不属于软件按钮。
