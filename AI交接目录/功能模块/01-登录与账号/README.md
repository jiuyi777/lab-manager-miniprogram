# 01-登录与账号

[设计图](设计图.png)

## 模块职责

代码归属：`pages/auth/login/；modules/auth/；data/seed.js`（相对于 `软件/miniprogram/`）。只处理本模块职责；跨模块数据通过服务接口调用。

## 01 身份选择

- A 选择登录身份；权限以账号为准。
- B 进入学号或工号登录表单。
- C 查看网络状态与连接帮助。

当前：演示账号选择已实现；正式角色登录待做。

## 02 账号登录

- A 输入学号或工号及密码。
- B 验证账号并进入对应首页。
- C 忘记密码时联系管理员重置。

当前：演示登录已实现；学号密码认证待后端。

## 03 修改密码

- A 验证当前密码。
- B 设置并再次确认新密码。
- C 保存新密码后重新登录。

当前：仅设计；首次改密与找回密码待做。

## 接续规则

- 先核对现有代码和上面的状态，再实现缺项，不创建第二套同名业务。
- 页面只处理交互与展示；权限、状态转换、校验集中在对应业务模块。
- 影响共用规则时检查其他页面与教室，修改源头并补相应测试。
- 图片里的 A/B/C 是评审标注，不属于软件按钮。
