# 07-审批与归还

[设计图](设计图.png)

## 模块职责

代码归属：`pages/admin/；modules/auth/policy.js；modules/bookings/actions.js`（相对于 `软件/miniprogram/`）。只处理本模块职责；跨模块数据通过服务接口调用。

## 19 管理工作台

- A 按权限范围查看待办统计。
- B 处理归还、维护与校准提醒。
- C 进入各管理模块；教师仅见授权入口。

当前：已实现老师/管理员待审和归还工作台；全量统计入口待做。

## 20 预约审批

- A 筛选授权范围内待处理申请。
- B 核对资格和时段后通过或驳回。
- C 批量审批；冲突申请单独提示。

当前：已实现单条审批、驳回必填、范围权限；批量审批待做。

## 21 归还确认

- A 核对使用人及实际使用时间。
- B 检查仪器、清理情况并记录备注。
- C 确认归还或转入维护处理。

当前：已实现用户结束时间与管理员确认时间分开记录；检查清单/转维护待做。

## 接续规则

- 先核对现有代码和上面的状态，再实现缺项，不创建第二套同名业务。
- 页面只处理交互与展示；权限、状态转换、校验集中在对应业务模块。
- 影响共用规则时检查其他页面与教室，修改源头并补相应测试。
- 图片里的 A/B/C 是评审标注，不属于软件按钮。
