## 模块职责

代码归属：`pages/bookings/list/、detail/；modules/bookings/actions.js`（相对于 `软件/miniprogram/`）。只处理本模块职责；跨模块数据通过服务接口调用。

## 10 我的预约

- A 按状态筛选预约与候补。
- B 查看仪器、时段和审批结果。
- C 根据状态签到、取消或查看原因。

当前：已实现按状态分组和详情入口。

## 11 预约详情

- A 核对仪器、时段、用途和样品。
- B 查看审批与使用进度。
- C 到场签到或取消未开始预约。

当前：已实现本人详情、取消、时段内签到。

## 12 使用中与结束

- A 查看实际开始时间和使用时长。
- B 关联记录并联系管理员报故障。
- C 提交结束，等待管理员归还确认。

当前：已实现结束使用及待归还；故障/延时操作待做。

## 接续规则

- 先核对现有代码和上面的状态，再实现缺项，不创建第二套同名业务。
- 页面只处理交互与展示；权限、状态转换、校验集中在对应业务模块。
- 影响共用规则时检查其他页面与教室，修改源头并补相应测试。
- 图片里的 A/B/C 是评审标注，不属于软件按钮。
