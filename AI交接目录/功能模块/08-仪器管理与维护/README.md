## 模块职责

代码归属：`modules/instruments/；classrooms/（管理页待建）`（相对于 `软件/miniprogram/`）。只处理本模块职责；跨模块数据通过服务接口调用。

## 22 仪器管理

- A 按实验室查找或新增仪器。
- B 查看启停状态及仪器资料。
- C 编辑、维护或停用并保留历史。

当前：只有设计和仪器查询代码；新增、编辑、停用管理待做。

## 23 编辑仪器

- A 维护名称、编号、位置与图片。
- B 编辑说明书、安全须知及校准档案。
- C 设置审批和培训要求并保存。

当前：仅设计；仪器档案编辑/上传/配置管理页面待做。

## 24 维护进度

- A 查看维护原因与当前状态。
- B 跟踪进度并处理受影响预约。
- C 管理员更新进度或确认恢复。

当前：仅设计；维护记录与受影响预约处理待做。

## 接续规则

- 先核对现有代码和上面的状态，再实现缺项，不创建第二套同名业务。
- 页面只处理交互与展示；权限、状态转换、校验集中在对应业务模块。
- 影响共用规则时检查其他页面与教室，修改源头并补相应测试。
- 图片里的 A/B/C 是评审标注，不属于软件按钮。
