## 模块职责

代码归属：`pages/home/；pages/instruments/；modules/instruments/；classrooms/`（相对于 `软件/miniprogram/`）。只处理本模块职责；跨模块数据通过服务接口调用。

## 04 学生首页

- A 搜索仪器、实验室和查看通知。
- B 查看今日预约并到场签到。
- C 新建预约或进入实验室列表。

当前：14页首版已有首页；与批准稿精细视觉对齐待开发者工具。

## 05 仪器列表

- A 搜索并按仪器状态筛选。
- B 查看位置和当前使用状态。
- C 选择未来时段或查看维护进度。

当前：已实现实验室筛选、名称搜索、当前状态筛选。

## 06 仪器详情

- A 查看仪器信息、位置与负责人。
- B 阅读使用方法、安全须知和档案。
- C 查看时间表并发起预约。

当前：已实现档案摘要、安全提示、占位列表和预约入口；真实图片/PDF待接。

## 接续规则

- 先核对现有代码和上面的状态，再实现缺项，不创建第二套同名业务。
- 页面只处理交互与展示；权限、状态转换、校验集中在对应业务模块。
- 影响共用规则时检查其他页面与教室，修改源头并补相应测试。
- 图片里的 A/B/C 是评审标注，不属于软件按钮。
