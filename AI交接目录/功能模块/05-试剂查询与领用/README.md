## 模块职责

代码归属：`pages/reagents/；modules/reagents/`（相对于 `软件/miniprogram/`）。只处理本模块职责；跨模块数据通过服务接口调用。

## 13 试剂台账

- A 搜索试剂并筛选库存或有效期。
- B 分别查看库存、临期和危险标识。
- C 进入详情或登记领用。

当前：已实现批次库存、过期拦截与低库存提示；搜索与临期筛选待做。

## 14 试剂详情

- A 核对名称、规格和库存单位。
- B 查看批次、柜位、有效期与安全须知。
- C 查领用记录；管理员可入库调整。

当前：详情并入领用页；完整安全资料、入库入口待做。

## 15 领用登记

- A 选择正确试剂与批次。
- B 填写数量、用途和关联样品。
- C 核对后登记并扣减库存。

当前：已实现整瓶领用、用途、库存流水与去重；页面样品选择待补。

## 接续规则

- 先核对现有代码和上面的状态，再实现缺项，不创建第二套同名业务。
- 页面只处理交互与展示；权限、状态转换、校验集中在对应业务模块。
- 影响共用规则时检查其他页面与教室，修改源头并补相应测试。
- 图片里的 A/B/C 是评审标注，不属于软件按钮。
