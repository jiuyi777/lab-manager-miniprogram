## 25 实验室管理

- A 新增或查找实验室。
- B 查看开放时段、负责人和仪器数。
- C 编辑、维护或关闭并检查预约影响。

当前：只有按实验室查询；管理页待做。

## 26 编辑实验室

- A 维护名称、房间编号和位置。
- B 设置负责人及开放时段。
- C 保存状态变更并处理关联预约。

当前：配置已独立落文件；管理表单及配置迁移待做。

## 27 用户名单

- A 按姓名、账号和角色查找用户。
- B 查看角色及授权实验室。
- C 新增、导入或编辑用户资料。

当前：演示账号来自种子数据；正式名单与批量导入待做。
