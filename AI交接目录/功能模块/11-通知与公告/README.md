## 31 通知中心

- A 筛选未读消息并标记已读。
- B 查看审批、候补及维护通知。
- C 跳转对应记录处理；仅站内提醒。

当前：已实现本站本机通知、标记已读；通知跳转与全部已读待做。

## 32 公告列表

- A 筛选普通与紧急公告。
- B 查看公告标题、时间和影响范围。
- C 展开全文；管理员可进入编辑。

当前：仅设计，公告模块未实现。

## 33 发布公告

- A 填写标题和公告优先级。
- B 编写正文并选择通知范围。
- C 预览后发布到公告与站内通知。

当前：仅设计，公告发布未实现。
